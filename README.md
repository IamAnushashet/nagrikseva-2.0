# NagrikSeva 2.0

A modern React government-services portal prototype with citizen workflows, application tracking, an AI assistant, and an admin dashboard.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Synthetic datasets

Generated JSON datasets live in `src/data/generated`.

```bash
npm run generate:data
```

The generator creates 1,000 citizens, 5,000 applications, 3,000 complaints, Aadhaar/PAN/DigiLocker records, and locality complaint intelligence.
